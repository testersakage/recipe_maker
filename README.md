# 🛠️ クラフトレシピメーカー (コード＆JSON自動生成ツール)

<img width=292, height=266, src="https://github.com/testersakage/recipe_maker/blob/main/screenshots/sample1.png"></img>

- [English Documentation (README.en.md)](./README.en.md)

Luanti (Minetest) のMOD開発を劇的に効率化させる、画期的なゲーム内ビジュアル開発支援ツールです。
作業台形式の3x3画面に素材アイテムを実際に並べるだけで、システム内のデータベースから現在起動している環境の100%正確なアイテムIDを直接読み取り、タイポ（打ち間違い）のないLuaクラフトコードおよびデータ駆動型JSON用配列文字列をその場で自動生成します。

ゲームのバージョンアップデートや環境（VoxeLibre / Mineclonia / Minetest Gameなど）によって木材や各種アイテムの命名規則（アンダースコアの有無やネームスペース）がコロコロ変わってしまう開発者の悩みを完全に解決します。

## 🌟 主な機能

- **本物のIDを直接スキャン**: 手持ちのブロックを枠に置くだけで、内部の `core.registered_items` から実在する正確なIDを直接吸い出します。手探りで調べる必要はもうありません。
- **マルチ出力フォーマット**: 標準的なLuanti用の `core.register_craft` 構文だけでなく、近年主流のデータ駆動型（JSON）の配列形式（`"recipe": [ ... ]`）も同時に一発出力します。
- **最適化されたGUIデザイン**: 自分の手持ちインベントリがすべて1画面で見渡せるよう、スロットサイズをコンパクトな `0.6倍` に縮小。配置場所を迷わせない半透明のダークグレー背景（座布団）を採用。
- **安全なドロップ破壊仕様**: 中にアイテムを入れたままツルハシ等でブロックを破壊しても、ロックがかからず、中の素材をその場にすべてポンポンと安全にばらまいて回収できます。

## 🛠️ 導入方法

1. このリポジトリをZIP形式でダウンロードするか、gitを使用してクローンします。
2. 展開したフォルダを、Luantiの `mods/` ディレクトリに移動します。
3. フォルダ名を正確に **`recipe_maker`** に変更します。
4. ワールドの設定画面からMODを**有効**にします。

## 💻 動作環境

- **最低環境**: **Luanti v5.4.0 以上** (新仕様のFormspec配置機能を使用しているため必須)。
- **推奨環境**: **Luanti v5.15.2 以上** (エンジンの最適化および、重要なセキュリティ対策パッチが適用されているため推奨)。

## 🚀 使い方

1. クリエイティブインベントリ等から「クラフトレシピメーカー（`recipe_maker:generator`）」を取り出し、地面に設置します。
2. ブロックを右クリックして専用の開発画面を開きます。
3. 左側の3x3枠にレシピの「素材」を並べ、中央右の1マス枠に「完成品」のアイテムを配置します。
4. **【コード生成】** ボタンを押します。
5. 下のテキストエリアに出力された Luaコード または JSON配列 をコピーして、自分のMODファイルに貼り付けるだけです！
